# liftrule

Lift URLs and rule query parts with stable normalization.

**Site:** https://theworker02.github.io/liftrule/

## Install / run

```bash
git clone https://github.com/theworker02/liftrule.git
cd liftrule
node src/cli.js
node --test
```
